このサイトについてAbout this site

ファイルはサーバに送られませんYour file never goes to a server

  • ファイルは、PC の画面に表示した模様をスマホのカメラで撮影して受け渡します。ファイルの中身がインターネットやサーバを通ることはありません。The file is passed as a pattern on the PC screen that the phone's camera captures. Its content never travels over the internet or through a server.
  • このサイトのサーバは、ページ（HTML と JavaScript）を配信するだけです。ファイルの読み込み、画面の模様への変換、撮影した映像からの復元は、すべてお使いの端末のブラウザの中で行います。The server only delivers the pages (HTML and JavaScript). Reading the file, turning it into screen patterns and rebuilding it from the camera images all happen in the browsers on your devices.
  • アカウント登録は不要です。このサイトが利用状況や診断情報を送信することはありません（受信ページの「診断情報を保存」は、端末に保存するだけです）。ページの配信元（GitHub Pages）には、一般的な Web サイトと同じく、ページを開いたときのアクセスの記録が残ることがあります。No account is needed. This site sends no usage or diagnostic data ("Save diagnostics" on the receive page only saves a file on your device). As with any website, the host (GitHub Pages) may keep access logs of page visits.
  • 今は開発用サーバで開いています。この場合に限り、受信の診断ログ（ファイルの中身は含みません）を開発用サーバに送ります。「撮影画像を送る」を押したときは、カメラの画像も送ります。This page is served by the development server. Only then, reception diagnostics (without the file content) are sent to it, and a camera image when "Send a capture" is pressed.

使う前に知っておいてほしいことBefore you use it

  • 画面が見える人は誰でも受け取れます。模様は暗号化していないので、周りから撮影されると内容を取り出されるおそれがあります。人に見られて困るファイルは送らないでください。Anyone who can see the screen can receive the file. The patterns are not encrypted, so someone filming the screen could recover the content. Do not send files that others must not see.
  • 受け取ったファイルは、送信側で計算したハッシュ値（SHA-256）と一致したときだけ保存できます。途中で誤りがあっても、壊れたファイルが保存されることはありません。受け取ったファイルが自動で開くこともありません。A received file can be saved only when it matches the sender's hash (SHA-256), so a corrupted file is never saved. Received files are never opened automatically.
  • 送信中は画面の模様が毎秒 20 回ほど切り替わります。光の点滅で気分が悪くなったことがある方は使わないでください。見るときは、送信画面の横幅以上離れてください。While sending, the pattern changes about 20 times per second. Do not use it if flashing light has ever made you unwell. Watch from at least the width of the sending pattern away.
  • 速さの目安は 1 MiB あたり 25〜30 秒で、64 MiB まで送れます。受信を始めるのが途中からでも、途中で画面から外れても、続きから集まります。It takes about 25–30 seconds per MiB, for files up to 64 MiB. Reception can start at any time and continues where it left off if the phone looks away.

動作を確認した環境Tested with

  • 送る側: Windows の PC と ChromeSending: Chrome on a Windows PC
  • 受け取る側: iPhone（iOS 18）の SafariReceiving: Safari on iPhone (iOS 18)
  • ほかの端末でも動くことがありますが、確認していません。近くの物にピントが合わないカメラ（一部のタブレットなど）や、処理の遅い端末では受け取れないことがあります。Other devices may work but are untested. Cameras that cannot focus up close (some tablets) and slow devices may fail to receive.

Visual Data Link は、ブラウザだけで画面からカメラへデータを送る実験的なソフトウェアです。動作や結果は保証しません。Visual Data Link is experimental software for screen-to-camera data transfer in the browser. It comes with no warranty.
